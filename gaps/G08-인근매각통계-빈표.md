# G08. 인근매각통계 표가 3,892건 전부 비어 있다

**상태**: 미해결 · **담당**: 세션 A · **우선순위**: 중

## 한 줄
법원이 주는 '동네 시세 통계'를 **머리글만 받아오고 있다.**

## 원인 (실제 화면으로 확인, 2026-09-16)
물건상세 화면에 **`인근매각통계`·`인근매각물건` 버튼이 따로 있다.**
표는 페이지 로드 시점에 머리글만 있고(rows=1), **버튼을 눌러야 채워진다.**
우리 크롤러는 그 버튼을 안 누른다.

## 결과
표본 4,000건 중 **데이터 있음 0건 / 빈 표 3,892건.**

법원이 주는 칸: `기간 · 매각건수 · 평균감정가 · 평균매각가 · 매각가율 · 평균유찰횟수`
(옥션원은 같은 자리에 `입찰인원수`와 자체 추정가까지 붙인다 — 그건 우리가 못 만든다)

## 고치는 법 — 된다. 우리가 이미 쓰는 방식이다

내가 브라우저에서 JS로 `el.click()`을 해서 실패한 것이지,
**Playwright의 `locator.click()`은 실제 마우스 이벤트를 만들어 보내므로 WebSquare가 받는다.**
`crawler._go_next_page`가 페이지 넘기기에서 **이미 그 방식으로 동작하고 있다.**

> 코드 주석 그대로: *"WebSquare 페이저(w2pageList)는 신뢰된 클릭(실제 마우스 이벤트)만 받는다."*

### 할 일
`detail_crawler`에서 물건상세를 연 뒤 `인근매각통계` 버튼을 `locator.click()`으로 누르고,
표가 채워질 때까지 기다린 뒤 긁는다. 같은 자리의 **`인근매각물건`** 버튼도 함께 볼 것.

## 확인
```python
# detail_json 안에서 caption에 '평균유찰횟수'가 든 표의 데이터 행 수를 센다 → 지금은 전부 0
```
