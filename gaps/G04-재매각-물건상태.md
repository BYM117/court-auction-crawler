# G04. 재매각 물건이 화면에서 구별 안 된다 — 보증금이 2배인데

**상태**: 미해결 · **담당**: 세션 B · **우선순위**: 높음 (돈에 직결)
**묶임**: G01 · G05와 같은 데이터. **한 번에 파싱할 것.**

## 한 줄
지금 입찰 가능한 1,312건이 과거에 낙찰됐다 깨진 물건인데, 목록엔 그냥 `유찰 N회`로 나온다.

## 왜 돈 문제인가
**재매각 물건은 매수신청보증금이 최저가의 20%다**(보통 10%).
비고에 '재매각'이 있는 활성 423건 중 **423건 전부**가 20%를 같이 적고 있다. **예외 없다.**
모르고 가면 보증금 부족으로 **입찰이 무효**가 된다.

## 원인
`enrichment.parse_special_rights`의 재료가 **목록 비고와 주소뿐**이다(`enrichment.py:274`).
상세의 기일내역·물건상태를 안 본다.

## 결과 (활성 32,132건 중)

| 이력 | 건수 |
|---|---|
| 과거에 낙찰됐던 물건 | **1,312** |
| 대금미납 | 1,074 |
| 매각불허가 | 213 |
| 매각허가취소 | 32 |
| 비고에 '재매각' (딱지가 붙는 것) | 419 |

**893건은 딱지 없이 '유찰 N회'로만 보인다.**

## 고치는 법 — 기일내역 파싱이 필요 없다

사건 화면의 **`물건상태`** 한 필드에 전체 이력이 문자열로 들어 있다.
**물건 단위라 형제 물건이 안 섞인다.** 표본 6,000건 중 **5,851건(97.5%)** 이 이미 갖고 있다.

| 물건상태 | 건수 |
|---|---|
| `매각준비 -> 매각공고` | 3,448 |
| `매각준비 -> 매각공고 -> 유찰` | 1,819 |
| `매각준비 -> 매각공고 -> 매각 -> 매각허가결정 -> 대급납부` | 353 |
| `매각준비 -> 매각공고 -> 매각 -> 매각허가결정` | 120 |
| `매각준비 -> 매각공고 -> 매각 -> 매각허가결정 -> 대금미납` | **84** |
| `매각준비 -> 매각공고 -> 매각 -> 매각불허결정` | **21** |
| `매각준비 -> 매각공고 -> 매각` | 6 |

`대금미납`·`매각불허결정`이 들어 있으면 재매각이다. **문자열 포함 검사 한 줄이면 된다.**

### ⚠ 함정: 법원 사이트 오타를 그대로 받아야 한다
**`대금납부`가 아니라 `대급납부`다.** `대금`으로 찾으면 353건을 통째로 놓치고 `대금미납`만 걸린다.
