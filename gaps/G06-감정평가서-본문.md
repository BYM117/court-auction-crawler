# G06. 감정평가서 5.5만 건이 '수집됨'인데 빈 껍데기다

**상태**: **요항표 수집 시작 · PDF 파일만 미해결** (2026-09-18, 세션 B) · **담당**: 세션 A→B

## 한 줄
상태가 거짓말을 하고 있어서 **오늘까지 아무도 몰랐다.** 지금은 사실상 요약본만 보여주는 꼴이다.

## 결과 (실측)

| 문서 | '수집됨' | 실제 내용 있음(>2KB) |
|---|---|---|
| 현황조사서 | 55,048 | 22,263 |
| 매각물건명세서 | 35,700 | 28,651 |
| **감정평가서** | **54,942** | **0** |

평균 길이 702바이트. 실제 PDF를 받은 건 **1건**(31MB).

## 원인 — 법원 서버에 없다

감정평가서는 **한국감정평가사협회(`ca.kapanet.or.kr`)** 에 있고 법원 화면은 iframe으로 띄울 뿐이다.
Adobe Reader 플러그인 기반이라 본문이 DOM에 안 들어온다.

우리가 저장해둔 metadata에 흔적이 남아 있다.
```json
"iframe": {
  "resources": ["https://get.adobe.com/kr/reader/",
                "https://ca.kapanet.or.kr/image/getacro.gif",
                "https://ca.kapanet.or.kr/825B2D1A/001/EF300039/000530-20240130000964-1-0000.pdf"],
  "url": "https://ca.kapanet.or.kr/view/000530/20240130000964/1/240126-19-0001/20240202"
}
```

## 우리가 이미 갖고 있는 것 (감정평가서 문서 56,081건 기준)

| | 건수 |
|---|---|
| 협회 뷰어 URL (`ca.kapanet.or.kr/view/...`) | **54,947 (98%)** |
| **PDF 직링크 (`.pdf`)** | **235 (0.4%)** |

## 고치는 법 — 순서가 중요하다

**1. 거짓 상태부터 고친다.**
`collected`가 아니라 `metadata_only`(또는 전용 값)로 바꾼다. **이게 제일 먼저다.**
지금은 "다 모았다"고 말하고 있어서 다음 사람도 속는다.

**2. 본문을 직접 가져온다.**
> 2026-09-16 사용자 방침: *"링크를 걸어서가 아니라 우리 사이트에서 직접 볼 수 있어야 한다."*

링크아웃은 사용자를 남의 사이트로 내보내는 것이라 답이 아니다.

**3. 받는 방법의 단서는 이미 있다.**
**PDF 직링크가 노출된 235건**이 있다. 어떤 조건에서 직링크가 드러났다는 뜻이다.
**그 조건을 찾으면 나머지도 열린다.** 뷰어 페이지를 열어 네트워크 요청을 보면
실제 PDF 경로가 드러날 가능성이 높다.

**4. 부하는 설계로 푼다.**
받은 1건이 31MB였다. 5만 건을 한꺼번에 받는 것은 제3자(협회) 서버에 무리다.
**기일 임박순으로 천천히 받고 캐시**하면 된다 — 어차피 기일 2주 전부터만 열리므로(`G16`)
자연스럽게 분산된다.

## 확인
```sql
SELECT document_type, COUNT(*), ROUND(AVG(LENGTH(metadata_json))),
       SUM(LENGTH(metadata_json)>2000)
  FROM auction_documents WHERE status='collected' GROUP BY 1;
```

## 2026-09-18 — 1번(거짓 상태)은 고쳤고, 2번(본문)은 원천 불가로 확정했다

### 거짓말의 출처

```python
has_content = len(metadata.get("text", "")) >= 200 or bool(
    metadata.get("iframe", {}).get("text")
    or metadata.get("iframe", {}).get("tables")
    or metadata.get("iframe", {}).get("resources"))
```

iframe 에 `resources` 가 **하나라도** 있으면 '내용 있음'이었다. 그런데 감정평가서
뷰어는 Adobe 안내 이미지(`getacro.gif`)와 "열람이 안될 경우…" 문구를 **항상** 보낸다.
본문을 한 글자도 못 받았는데 56,123건이 `collected` 가 된 이유다.
`CLAUDE.md` 함정 ⑤-1 의 전형 — **결과가 아닌 것을 결과의 대용으로 삼았다.**

### 판정을 세 번 고쳤다

| 시도 | 왜 틀렸나 |
|---|---|
| `resources` 가 있으면 내용 | Adobe 아이콘이 늘 온다 |
| PDF 주소를 가지면 내용 | 주소는 받아 올 실마리지 **가진 것이 아니다** |
| 바깥 `text` 200자 이상이면 내용 | 그 글자는 법원 화면의 **머리표**(법원·사건번호·명령회차)다 |

세 번째가 특히 고약했다. 길이로는 못 가른다 — 실측 분포가 겹친다.

```
감정평가서      최소  82 · 중앙 203 · 최대  324
현황조사서      최소 277 · 중앙 823 · 최대 17,667
매각물건명세서   최소 463 · 중앙 1,874
```

그래서 길이가 아니라 **구조**로 가른다. 본문을 남의 뷰어에 맡긴 문서는 **그 뷰어가
비어 있으면 본문이 없는 것**이고, 바깥 글자가 몇 자든 상관없다.
`detail_crawler.document_has_body` 하나에 두고 교정 스크립트도 그것을 쓴다.

### 결과

| 문서 | 이전 `collected` | 지금 `collected` | 실제 본문(2KB↑) |
|---|---|---|---|
| **감정평가서** | 56,123 | **6** | 0 |
| 현황조사서 | 56,231 | 56,231 | 22,731 |
| 매각물건명세서 | 35,946 | 35,946 | 28,848 |

**다른 두 문서는 그대로다** — 판정이 과하지 않다는 증거다.
남은 6건은 실제로 파일을 내려받은 것이다.

```bash
python3 scripts/g06_fix_status.py --dry-run   # 다시 재려면
```

### 본문은 못 가져온다 — 세 갈래로 확인했다

1. **네트워크 요청 청취** → PDF 요청 **0개**. 플러그인이 없으니 `embed` 가 요청을 안 낸다.
2. **안쪽 프레임** → `about:blank`, 39바이트.
3. **뷰어 원본 HTML** → **988바이트에 스크립트가 없고 `<iframe src="">` 가 영원히 빈 채**다.

```html
<iframe name="F1290578539" id="F1290578539" src="" frameborder=10 ...></iframe>
```
서버가 src 를 채우지 않는다. 채우는 스크립트도 없다. 플러그인이 있는 브라우저에서만
Adobe 가 직접 그리는 구조다.

### '직링크 235건'은 조건이 아니라 타이밍이었다

이 문서는 *"어떤 조건에서 직링크가 드러났다. 그 조건을 찾으면 나머지도 열린다"* 고
적었는데, 재현 가능한 조건이 아니다. **235건 중 202건이 수집 첫 달(2026-07)에 몰려
있다.** `source_url`·`content_type` 어느 것도 나머지와 다르지 않다. 수집 당시 요청이
우연히 스냅샷에 걸린 산물이다.

### 결론

`CLAUDE.md` 함정 ⑧ 이 맞았다. **법원 경로로는 감정평가서 본문을 못 얻는다.**
링크아웃은 사용자 방침상 답이 아니므로, 남은 길은 협회와의 별도 합의뿐이다.
그건 코드로 풀 문제가 아니다.

**다만 이제 상태가 사실을 말한다.** 56,221건이 `metadata_only` 이고, 뷰어 URL은
metadata 에 그대로 있어 길이 열리면 바로 쓸 수 있다.

## 2026-09-18 재조사 — **'원천 불가' 는 과했다. 90%는 풀렸고 마지막 한 칸이 막혔다**

사용자 지적("어떻게든 가져와야 할 거 아니냐")을 받고 다시 팠다. 결과가 달라졌다.

### PDF 는 **실제로 받아진다**

알려진 주소로 직접 받아 봤다.

```
GET https://ca.kapanet.or.kr/825B2D1A/001/EF300327/B12408-H-1601.pdf
→ 200 · application/pdf · 35,193,809 bytes · %PDF- 로 시작
```

**문이 잠긴 게 아니다. 주소를 못 만들 뿐이다.**

### 주소 규칙 — 네 칸 중 세 칸을 풀었다

199개 짝(뷰어 URL ↔ PDF URL)을 맞대 봤다.

```
뷰어  /view/000530/20240130004386/1/2124-04-30012/20240607
PDF   /825B2D1A/001/EF30136M/2124-04-30012.pdf
       └───┬───┘ └┬┘ └──┬──┘ └──────┬──────┘
        고정      고정   ???      뷰어의 4번째 칸
```

| 칸 | 값 | 아는가 |
|---|---|---|
| 접두 | `825B2D1A` | ✅ 199/199 동일 |
| 버킷 | `001` | ✅ 196/199 (나머지 `002`) |
| **폴더** | `EF30136M` 등 | ❌ **못 구한다** |
| 파일명 | 뷰어 4번째 칸 + `.pdf` | ✅ 규칙 확인 |

### 폴더가 안 풀리는 이유 — 규칙이 아니라 배정이다

**25개 기관이 141개 폴더**를 쓴다. 같은 기관의 문서가 서로 다른 폴더에 흩어져 있고,
한 폴더에 여러 기관이 섞여 있다(`EF403756` 에 `000250` 과 `000254`).
업로드 시점에 배정되는 저장소라 뷰어 주소에서 계산할 수 없다.

### 막힌 길 네 개 — 전부 실제로 두드려 봤다

| 시도 | 결과 |
|---|---|
| 네트워크 요청 청취 | PDF 요청 0개 |
| **브라우저 창 띄우고 플러그인 켜기** | 그래도 0개. 12초 기다려도 안 나온다 |
| 안쪽 프레임 파고들기 | 자기 자신을 다시 부를 뿐 |
| 변환 입구 추정(`/pdf/`·`/download/`·`.pdf` 붙이기) | 전부 HTML, PDF 아님 |

뷰어 원본 HTML 은 988바이트에 스크립트가 없고 `<iframe src="">` 가 **끝까지 빈 채**다.
서버가 채우지 않고, 채울 스크립트도 없다. **사람이 브라우저로 봐도 같다.**

### 그래서 남은 길은 코드가 아니다

- **협회(`ca.kapanet.or.kr`)에 요청**하는 것. 회원제 사이트다.
- 또는 **법원에 요청**하는 것. 법원 DB 는 뷰어 링크를 만들 줄 아니 전체 경로를 안다.

둘 다 사람이 할 일이지 코드로 풀 문제가 아니다.

### 지금 당장 되는 것

**우리가 이미 주소를 가진 199건은 받을 수 있다.** 내려받는 코드는 이미 있고
(`_download_resource`, 실제로 1건 31MB 를 받아 뒀다) 주소만 있으면 동작한다.
다만 **문서 조회 창**이 있어 기일이 지난 것은 162바이트 안내문이 온다(함정 ⑦).

**폴더 규칙만 알아내면 나머지 5.5만 건이 그대로 열린다.** 파일명과 접두는 이미 풀렸다.

## ★ 정정 — '원천 불가' 는 **틀린 결론이었다** (2026-09-18, 같은 날)

사용자 지적: *"그럼 옥션원은 어떻게 받아와?"*

경쟁사가 보여주고 있으면 길이 있다는 뜻인데, 나는 **내가 막힌 길 하나만 보고 없다고
결론 냈다.** 질문을 *"감정평가 내용을 보여줄 수 있나"* 가 아니라 *"PDF 파일을 받을 수
있나"* 로 좁혀서 답한 것이다.

### 법원이 화면에 **텍스트로 준다**

물건상세 화면에 `감정평가요항표 요약` 이 있다. 평가사가 쓴 문장 그대로다.

```
1) 위치 및 주위환경   본건은 전남 광양시 중동 "중진초등학교" 서측 인근에 위치하는
                   "성호2차아파트 제201동 제20층 제2008호" 이고, 부근은 아파트단지,
                   근린생활시설, 공원, 학교 등이 혼재하는 아파트지대이며...
2) 교통상황         차량출입이 가능하며, 인근에 버스정류장 및 간선도로 등이 소재하여...
3) 건물의 구조       철근콘크리트 벽식구조 평슬래브지붕 23층건 중 제20층 제2008호로서,
                   외벽 : 몰탈 위 페인팅 / 내벽 : 벽지, 타일 / 창호 : 샷시창호
                   사용승인일 2009.12.30
4) 이용상태         아파트로 이용중임
5) 설비내역         위생설비, 급배수설비, 승강기설비, 소화전설비, 도시가스 난방
6) 토지의 형상       부정형...
```

**옥션원이 보여주는 것도 이것이다.** PDF 를 뚫은 게 아니다.

### 왜 0건이었나 — 추출기 둘 사이로 빠졌다

| 추출기 | 보는 것 |
|---|---|
| `extract_tables` | `<table>` 만 |
| `extract_sections` | `h2`,`h3`,`h4` 제목만 |
| **요항표 블록** | 제목도 내용도 `<div>` → **아무도 안 봤다** |

실측: 최근 400건 중 **0건** 보유.

### 고친 뒤

`extract_appraisal_summary` 를 붙였다. 제목 div 의 다음 형제를 본문으로 잡고,
화면이 바뀌어 그 관계가 깨지면 '위치 및 주위환경' 을 품은 가장 안쪽 요소로 되짚는다.
payload 는 `property.appraisal_summary`.

**수집기 경로로 12건 중 12건** 담겼다. 물건 종류를 안 가린다.

```
오피스텔 606 · 다세대 789 · 임야 518 · 아파트 462 · 빌라 1,058
기타 1,037 · 전답 230 · 자동차 368 · 전답 1,458   (단위: 자)
```

### 그래서 지금 상태

| | |
|---|---|
| **감정평가 내용**(위치·환경·교통·구조·설비·이용상태) | ✅ **받는다** |
| 감정평가서 PDF 원본(서명·사진·도면) | ❌ 저장 폴더를 못 구한다 |

PDF 쪽 조사(주소 규칙 3/4 풀림, 폴더는 배정이라 계산 불가)는 위에 그대로 둔다 —
폴더 규칙만 알면 그것도 열린다. **다만 그게 없어도 화면에 보여줄 내용은 확보했다.**

### 남길 교훈

**"안 된다" 로 닫기 전에 '남들은 어떻게 하나' 를 봐야 한다.** 막힌 길 하나를 네 가지
방법으로 두드린 것은 성실했지만, 그 길이 유일한 길인지는 확인하지 않았다.
