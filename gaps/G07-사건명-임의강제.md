# G07. 임의경매/강제경매를 갖고도 안 내보낸다

**상태**: 미해결 · **담당**: 세션 B · **우선순위**: 낮음(쉬움)

## 한 줄
권리 분석이 갈리는 구분인데 payload에 안 실린다. **데이터는 이미 있다.**

## 원인
사건 기본 내역의 `사건명` 칸을 파싱하지 않는다.

## 결과 (표본 8,000건)

| 사건명 | 건수 |
|---|---|
| 부동산임의경매 | 4,491 |
| 부동산강제경매 | 3,071 |
| 공유물분할을위한경매 (+부동산) | 110 |
| 청산을위한형식적경매 (+부동산) | 74 |
| 자동차임의경매 | 42 |
| 소형선박임의경매 | 8 |

옥션원은 `경매절차(임의/강제)`를 검색 조건으로 쓰고, 특수물건에 **형식적경매 4종**을 둔다.

## 왜 중요한가
- **임의경매**: 담보권 실행. 근저당 등이 근거.
- **강제경매**: 판결 등 집행권원. 근거가 다르고 취소 가능성·권리 관계가 다르다.
- **형식적경매**(공유물분할·청산 등): 성격이 완전히 다르다.

## 고치는 법
1. `사건명`을 파싱해 payload에 `auction.case_type`으로 더한다. **필드 추가라 안전하다.**
2. `형식적경매`가 들어간 사건명은 `special_rights`에도 넣는다.

