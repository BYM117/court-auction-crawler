## 이 나눔이 맞는 이유
오늘 조사의 결론이 *"우리는 거의 다 받아놨고 안 읽고 있다"* 였다.
**그래서 일의 대부분이 B(읽는 일)에 몰린다.** A(더 받는 일)는 G15를 빼면 작다.
마침 다른 세션이 이미 A에 들어가 있으니 자연스럽다.
