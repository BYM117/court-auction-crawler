# 정답지 — 규칙과 Jev 를 재는 기준

**여기가 "진화" 의 기준이다.** 규칙(`rights.py`)이나 Jev 질문(`jev.QUESTIONS`)을 고치면
`scripts/jev_eval.py` 로 이 정답지를 다시 재고, **지금까지 최고점보다 떨어지면 반영하지 않는다.**

| 파일 | 무엇 | 정답 칸 |
|---|---|---|
| `waiver.json` | 비고 — 대항력 포기 뒤에도 위험이 남나 | `risk` |
| `lien.json` | 비고 — 유치권이 해소됐나 | `status` 해소/남음 |
| `occupancy.json` | 현황조사서 — 조사관이 점유자를 직접 만났나 | `met` |
| `senior.json` | 매각물건명세서 — 최선순위 설정일 | `dates` |
| `names.json` | 비고 — 문장 속 실명 | `name_hashes` |

**본문과 실명은 저장소에 두지 않는다.** 물건 키·문서 id 와 정답, 본문 지문(`text_fp`)만
둔다. 본문은 채점할 때 DB 에서 읽는다. 실명 정답은 `sha256("jev-name:"+이름)` 앞 16자다.
본문이 정답을 매길 때와 달라지면(지문 불일치) 채점에서 빠지고 따로 세어진다.

## 키우는 법

1. 사이클이 규칙과 Jev 가 엇갈린 물건을 모은다 → `python3 scripts/jev_review.py`
2. 본문을 읽고 정답을 매긴다 → `python3 scripts/jev_review.py --add <키> waiver true`
3. 다시 잰다 → `python3 scripts/jev_eval.py`
4. 규칙이 틀렸으면 `rights.py` 를, Jev 가 틀렸으면 질문 문구를 고치고 **버전을 올린다.**
   eval 을 통과할 때만 커밋한다.

## 정답을 매길 때 지킬 것 (2026-09-23 에 밟은 것)

- **질문을 본 표본으로 고쳤으면, 그 표본은 정답지로만 쓰고 검증은 새 표본으로 한다.**
  같은 표본으로 고치고 재면 점수가 부풀려진다(`tag: 깨끗한검증` 이 새 표본이다).
- **본문을 끝까지 읽는다.** 1,400자까지만 읽고 매긴 정답 하나가 틀렸다 — 여러 호실짜리
  현황조사서의 13번째 호실에 답이 있었다.
- 틀리는 방향을 본다. 위험을 안전이라 하는 것(놓침)이 반대(헛경고)보다 비싸다.
